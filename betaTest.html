dicotic in the browser

Modeled after the iOS home screen: two channels, per-channel Balance (−1 = full left, +1 = full right, 0 = center), separate volumes, and swap queues. Load files from this device or from folders your system exposes (including synced cloud storage).

Beta. Nothing is uploaded. Streaming services are not wired yet. Use headphones to hear stereo balance clearly. If you open this page as file:// and hear no sound, run a tiny local server (e.g. python3 -m http.server in this folder) and use http://localhost:8000/betaTest.html — Chrome needs a proper origin for Web Audio to resume reliably after createMediaElementSource.
